# Calender 📅
Simple Program to display Calender of months and related things related to calenders and dates.
Please check out the '**-h**' flag while running the program to learn to use it. 
`./calender -h`

I also Have a file named '**How_Does_This_Work.txt**'. It explains the logic I used 
to make this program.

## Compiling and running Running:
All *.c file and *.h files are part of the source code and need to be compiled 
with your compiler on your platform OS. There's also a precompiled **linux** binary 
called '**calender**' in the repo, if you want that.

### Here's specific instructions (for linux) , though you might not need this:
First clone the repo with the following command on your terminal
```
git clone https://github.com/BigMetalUncle/Calender/
```
Move into the directory and run the following to compile
```
gcc -Wall main.c calender-related-functions.c processing-functions.c -o calender
```
Test the compiled program with '**-h**' flag and learn to use it:
```
./calender -h
```
Hope you liked the program 🔥
